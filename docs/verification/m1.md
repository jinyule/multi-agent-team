# M1：独立服务与桌面验证记录

日期：2026-09-12。环境：Apple Silicon macOS，Go 1.27.0，Node.js 24.16.0。依赖固定在 go.sum 和 desktop/package-lock.json。

## 验收结论

已实现项目注册、目标保存、六名固定成员、SQLite 事务持久化、请求去重、事件游标、本地 Unix socket 服务与 Electron/React 工作台。桌面退出不结束服务，服务被强制终止后重启可恢复目标并去重先前请求。

`make check` 全部通过，包含 Go race 检查、SQLite/HTTP 集成、真实服务进程 E2E、TypeScript 检查、桌面构建和真实 Electron 窗口 E2E。`go vet ./...` 通过。截图已人工式视觉检查，内容可读，没有发现溢出或遮挡。
